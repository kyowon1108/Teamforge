# Document Language Policy

## 기본 원칙

TeamForge 내부 운영 문서의 기본 언어는 한국어다.

이 정책은 신규 문서 생성과 기존 문서 수정 모두에 적용한다. 별도 예외가 명시되지 않은 한, 문서 본문과 설명 문장은 한국어로 작성한다.

## 적용 범위

다음 경로와 문서 생성 규칙에 적용한다.

- `docs/`
- 프로젝트 전용 Claude 운영 문서 (`CLAUDE.md`, `.claude/commands/`, `.claude/agents/`)
- 문서 생성 템플릿 (`docs/_templates/`)
- 문서 생성 스킬 및 에이전트 규칙

## 영어 유지 대상

다음 항목은 원문 영어를 유지한다.

- 파일 경로, 디렉터리명, 파일명 slug
- 코드, 타입, 인터페이스, 함수, 클래스, Prisma 모델명
- API path, HTTP method, 이벤트명, 환경 변수명, CLI 명령어
- 외부 서비스, 라이브러리, 제품의 고유 명칭
- 코드 블록과 JSON 예시의 식별자

## 문서 작성 원칙

- 문서 제목, 배경, 결론, 이유, 영향 범위, 절차 설명, 리뷰 코멘트는 한국어로 작성한다.
- 표 안의 설명 문장도 한국어를 기본으로 한다.
- 예시 명령어, 코드 조각, 경로 표기는 영어 원문을 유지한다.
- 파일명은 기존 규칙대로 영어 `kebab-case`를 유지한다.

## 기존 문서 전환 원칙

- 신규 문서는 모두 한국어로 작성한다.
- 기존 문서는 일괄 번역하지 않는다.
- 기존 문서를 수정할 때는 수정한 섹션부터 한국어 기준으로 정리한다.

## 예외

- 루트 `README.md`와 외부 공개 가능성이 높은 README 문서는 영문 또는 한영 병기를 허용한다.
- 외부 표준 문서를 그대로 인용하는 경우, 핵심 설명은 한국어로 쓰고 식별자와 원문 명칭은 유지한다.
